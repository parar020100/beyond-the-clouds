# beyond-the-clouds-reborn

## Original datapack summary
Beyond the Clouds adds a new dimension that's... well, beyond the clouds!

## What is this fork?
In this project, I have been working on upgrading the datapack for my personal needs  
However, I'll be happy to see it used by others  
  
Here are some of the upgrades
- added support moving on transport (boats, minecarts) and mobs (camels, horses, etc.) between dimensions  
- added support for travelling between words with the use of happy ghasts and elytras (they have different effects than the original mobs)  
- cleaned up code for some unused features
- tweaked some options (like world entry height - changed to 512+ blocks)  
- made travelling down to overworld smooth but a bit less safe, as it makes the game more interesting in my opinion  
- **partially merged the above world generation with [Maa](https://modrinth.com/user/ListenMaaFlow)'s Sky Islands** datapack
  
### The datapack includes:
- One new dimension
  - In the form of floating islands
  - Accessed by going above y level 448 in the overworld
  - Left by going below y level -48 in the dimension
- Six new biomes
  - The Cherry Islands
  - The Lush Islands
  - The Flower Forest Islands
  - The Dark Forest Islands
  - The Frozen Grove Islands
  - The Autumnal Forest Islands
- One new structure
  - The Sky Village, a floating island version of a regular village.
- Three new advancements
  - One granted for reaching the dimension
  - Another granted for exploring a Sky Village
  - Another granted for exploring all 5 new biomes
